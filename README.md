# Projeto Web – Validação de Formulários e Integração com API

## 1. Apresentação do Trabalho

Este trabalho tem como foco principal a **verificação e validação de formulários**, bem como a **integração com APIs** em uma aplicação web. Como parte complementar do projeto, foi desenvolvido e integrado um **jogo da velha**, com o objetivo de enriquecer a interface, demonstrar manipulação do DOM e aplicação de lógica em JavaScript.

A aplicação foi construída utilizando HTML, CSS e JavaScript, prezando pela organização do código, experiência do usuário e consistência visual.

## 2. Objetivos

### 2.1 Objetivo Geral

Desenvolver uma aplicação web que valide corretamente os dados de um formulário e realize integração com uma API, aplicando conceitos fundamentais de desenvolvimento front-end.

### 2.2 Objetivos Específicos

* Implementar validações de formulário no lado do cliente
* Garantir feedback visual adequado ao usuário durante o preenchimento
* Realizar consumo de API utilizando JavaScript
* Organizar o layout da página de forma clara e responsiva
* Integrar funcionalidades adicionais (jogo da velha) sem interferir no funcionamento principal do sistema

---

## 3. Tecnologias Utilizadas

* **HTML5**: Estrutura da página, formulário e componentes visuais
* **CSS3**: Estilização da aplicação, organização do layout e responsividade
* **JavaScript**: Validação do formulário, consumo de API, manipulação do DOM e lógica do jogo da velha

---

## 4. Estrutura de Arquivos

O projeto foi organizado de forma modular, separando responsabilidades:

* `index.html`: Estrutura principal da página, formulário e área do jogo
* `css/`: Arquivos de estilo da aplicação
* `js/`: Scripts responsáveis pela validação do formulário, integração com API e funcionalidades do jogo

Essa estrutura facilita a manutenção e compreensão do código.

---

## 5. Validação de Formulários (Parte Principal)

A validação do formulário foi implementada em JavaScript, garantindo que os dados inseridos pelo usuário atendam aos critérios definidos antes do envio.

As validações incluem:

* Verificação de campos obrigatórios
* Validação de formato (como e-mail e outros dados)
* Feedback visual imediato em caso de erro ou sucesso

Essas validações contribuem para a integridade dos dados e melhor experiência do usuário.

---

## 6. Integração com API (Parte Principal)

A aplicação realiza consumo de API utilizando JavaScript, permitindo:

* Envio de dados do formulário para a API
* Recebimento e tratamento da resposta
* Atualização dinâmica da interface com base nos dados retornados

Essa etapa demonstra o uso de requisições assíncronas e manipulação de dados externos.

---

## 7. Jogo da Velha (Parte Complementar)

O jogo da velha foi desenvolvido como funcionalidade adicional, não sendo o foco principal do trabalho.

Ele tem como objetivos:

* Demonstrar manipulação do DOM
* Aplicar lógica de programação em JavaScript
* Enriquecer a interface da aplicação

### Funcionalidades do jogo:

* Tabuleiro 3x3
* Alternância entre jogadores X e O
* Verificação de vitória e empate
* Placar de partidas
* Botão para reiniciar o jogo

---

## 8. Layout e Organização Visual

A página foi organizada em seções bem definidas, com destaque para o formulário e a área de integração com a API. O jogo da velha foi inserido em um card separado, próximo ao formulário, sem comprometer o fluxo principal da aplicação.

Foram aplicadas técnicas de CSS para garantir alinhamento, centralização e estabilidade do layout.

---

## 9. Responsividade

O projeto foi desenvolvido considerando diferentes tamanhos de tela, garantindo:

* Boa visualização em dispositivos móveis
* Ajuste automático dos componentes
* Manutenção da usabilidade em diferentes resoluções

---

## 10. Conclusão

O trabalho atingiu seu objetivo principal ao implementar corretamente a validação de formulários e a integração com API em uma aplicação web. A adição do jogo da velha como funcionalidade complementar permitiu demonstrar conhecimentos adicionais em JavaScript e manipulação do DOM, sem comprometer o funcionamento central do sistema.

O projeto evidencia a importância da organização do código, da validação de dados e do uso de APIs no desenvolvimento de aplicações web modernas.
